# 训练周

Android 健身周计划应用，cursor中调用Grok4.7 ,使用 .NET MAUI 开发。
只支持安卓。

做这个的出发点是自己健身时老是忘记组数和休息时间，记录吃的食物又是一个软件，找了应用商店里，发现各个都要钱，干脆自己做一个纯免费的。

特点：
用一个app解决健身时 练和吃的记录问题。

新建任务可以选择力量训练和有氧训练。
  预设了组数和休息间隔。
  预设了训练项目。

置顶的“摄入营养”卡片展示热量、蛋白质、脂肪、碳水、膳食纤维、钠。
  “摄入营养”卡片右侧“+”号键，可以添加食材，预设了各种食材的克重。可以自行调整。
  “摄入营养”卡片右侧“i”按钮，可以打开今日摄入营养的统计。

## 环境

- .NET 9
- .NET MAUI 的 Android 工作负载

## 构建与测试

```bash
dotnet build WeekPlan.sln
dotnet test WeekPlan.sln
```
